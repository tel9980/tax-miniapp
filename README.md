# 税优政策库（税收优惠政策浏览平台）

> 最新税收优惠政策，自动抓取国家税务总局政策法规库，免费、免备案、零运维。

## 这是什么

一个面向「个人 + 企业」的**税收优惠政策浏览、查看**平台，不是计算器。

核心能力：**政策一变，自动同步**。数据直接来自国家税务总局政策法规库（fgk.chinatax.gov.cn）官方接口，Worker 每次请求自动抓取最新政策、结构化、判定优惠、按税种/优惠类型分类，前端实时展示。无需人工维护，官方发了新政策，约 1 小时内自动出现在页面上。

## 线上地址

**https://jy.1211.cc.cd**

## 功能

- **政策列表**：最新政策按日期倒序展示（标题 / 文号 / 成文日期 / 发文单位 / 效力等级）
- **只看优惠**：默认只显示「税收优惠」政策（免征 / 减税 / 退税 / 扣除抵免等）
- **税种筛选**：增值税、企业所得税、个人所得税、消费税、关税及进出口、房产税、城镇土地使用税、土地增值税、车辆购置税、车船税、印花税、契税、资源税、环境保护税等
- **优惠类型筛选**：免税 / 减税 / 退税 / 扣除抵免 / 减免优惠
- **关键词搜索**：搜标题或文号
- **原文跳转**：点卡片直达国家税务总局原文
- **地区 / 区域筛选**：全国、广东，以及横琴 / 前海 / 南沙 / 大湾区等区域优惠专题
- **所得税到期地图**（`/api/cit-continuity`）：24 条企业所得税优惠逐条标注**长期有效 / 有效至某日 / 待核实 / 已到期**，区分「写在企业所得税法里的长期政策」和「靠文件一年一续的限时政策」（`worker/citContinuity.js`，静态数据）
- **增值税新法衔接表**（`/api/vat-continuity`）：依据《增值税法》+ 财政部 税务总局公告 2026 年第 10 号，逐条列出 58 项增值税优惠在 2026 年新法下**继续有效还是已停止**，每条带大白话解释 + 公告条款出处（`worker/vatContinuity.js`，静态数据，不依赖抓取）

## 架构

```
┌─────────────────────────────────────────────────────────┐
│  浏览器  jy.1211.cc.cd（Cloudflare Worker + 静态资源）      │
│                                                         │
│  前端 web/（index.html + app.js）                        │
│    └─ fetch /api/policies ──► Worker 逻辑                │
│                                                          │
│  Worker worker/index.js                                 │
│    ├─ Cache API 命中？ ── 是 ──► 直接返回（<10ms）          │
│    └─ 否（首次/缓存过期）                                    │
│         ├─ 并行抓 8 个官方栏目（各最新 50 条）               │
│         ├─ 结构化 + 优惠关键词判定 + 税种分类 + 去重排序      │
│         ├─ 写入 Cache API（缓存 1 小时）                   │
│         └─ 返回 JSON                                     │
│                                                          │
│  数据源：国家税务总局政策法规库 fgk.chinatax.gov.cn          │
│  接口：POST www.chinatax.gov.cn/getFileListByCodeId      │
└─────────────────────────────────────────────────────────┘
```

**为什么免费、为什么不用备案、为什么不用数据库**：

- **免费**：Cloudflare Workers 免费额度（10 万次请求/天）远超政策浏览需求；Worker 内置 Cache API 免费，无需 KV / D1 等付费绑定。
- **免备案**：走 Cloudflare 边缘 + 自有域名 `jy.1211.cc.cd`，不经过国内服务器，无需 ICP 备案。
- **无数据库**：政策数据量小（几百条），用 Cache API 内存缓存即可，每小时自动刷新，无需持久化数据库。

## 数据源细节

- **来源**：国家税务总局政策法规库 8 个栏目（财税文件、税务规范性文件、政策法规文件、法律、行政法规、国务院文件、其他文件、工作通知），每栏目取最新 50 条。
- **接口**：`POST https://www.chinatax.gov.cn/getFileListByCodeId`，参数 `codeId=''` + `channelId=<栏目UUID>` + `page` + `size`。
- **优惠判定**：官方列表接口不返回「是否税收优惠」标注字段，故用**关键词**判定（免征 / 免税 / 减征 / 减半 / 减按 / 退税 / 即征即退 / 留抵退税 / 加计扣除 / 抵免 / 减免 / 优惠 / 零税率 / 税收返还等），命中即标记为「优惠」并归类。
- **同步策略**：请求时惰性抓取 + Cache API 缓存 1 小时。即官方发新政策后，最多 1 小时内自动同步到线上（下次请求触发重新抓取）。

## 本地开发与部署

```bash
# 部署到 Cloudflare（需 CLOUDFLARE_API_TOKEN / CLOUDFLARE_ACCOUNT_ID）
npx wrangler deploy

# 本地预览（可选）
npx wrangler dev
```

自定义域名在 `wrangler.toml` 的 `[[routes]]` 配置，`jy.1211.cc.cd` 部署时自动建子域并签发证书。
