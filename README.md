# 税收优惠小程序 —— 产品方案 + 代码原型

> 一套面向「**个人 + 小微企业主**」的税务筹划微信小程序。覆盖个税计算、专项附加扣除、年终奖优化、小微企业/个体工商户优惠测算、增值税与开票筹划、税率速查与政策库。

---

## 一、产品定位与目标用户

| 维度 | 说明 |
|---|---|
| **目标用户** | 综合：① 工薪族/自由职业个人纳税人；② 个体工商户、小微企业主 |
| **核心价值** | 用**可视化的最优结果**帮用户在合法范围内少交税，省去翻政策、算税表的门槛 |
| **差异化** | 「自动选优」而非「只给算法」——年终奖两种方式自动取更优、小微税负自动判断是否达标 |
| **合规底线** | 只做**测算与提示**，不做规避；所有页面标注「以税务机关核定为准」 |

---

## 二、功能架构

```
税收优惠小程序
├── 首页（身份切换：个人/企业/综合 + 功能入口 + 最近计算）
├── 个人端
│   ├── 个税计算器（工资薪金月/年税额、到手测算、适用档位）
│   ├── 年终奖优化（单独计税 vs 并入综合，自动选优 + 跳档临界提示）
│   └── 专项附加扣除（7项汇总测算 + 大病医疗汇算退税）
├── 企业端
│   ├── 小微优惠测算（企业所得税5%实际税负 + 增值税免征）
│   └── 增值税/开票筹划（免税额度、六税两费减半）
├── 计算器（Tab：综合/年终奖/个体经营 税率速查）
└── 政策库（Tab：政策按 个人/企业 分类速览）
```

## 三、核心优化方案（重点交付内容）

### 3.1 税务算法优化 —— 从「算得对」到「算得优」

| 优化点 | 现状 | 优化后 |
|---|---|---|
| **年终奖计税** | 只算一种方式 | 同时计算「单独计税」「并入综合所得」，**自动取更省的方式并给出省税额** |
| **跳档临界提示** | 无 | 检测奖金落在税率跳档临界区间，主动提示「多发可能多交税」 |
| **小微税负判断** | 只给税率 | 自动判断是否满足「年所得≤300万」，不满足时提示全额25%的差异 |
| **专项附加** | 单项查询 | 7项汇总为「月扣除额 + 年扣除额 + 明细」，含大病医疗汇算测算 |
| **汇算退税** | 无 | 简化的「已预缴 vs 应缴」退税/补税测算 |

### 3.2 用户体验优化

1. **默认值填充**：表单预填常见数值（如月薪1.5万），用户「一改一算」即得结果，降低空表单阻力。
2. **结果即反馈**：计算结果用大字号高亮、红绿色区分「更优/需补税」，一眼看到关键结论。
3. **最近计算历史**：本地缓存最近20条，首页一键复用，减少重复输入。
4. **身份分流**：首页一键切换个人/企业，避免无关功能干扰，提升转化与留存。
5. **结论前置**：每个页面「建议」放在数值之前，先告诉用户该怎么做，再展示推导。

### 3.3 技术/性能优化

- **纯前端本地计算**：税务算法在 `utils/taxCalculator.js` 本地运行，**无网络依赖**，秒出结果、离线可用，合规且零成本。
- **税率表数据驱动**：档位集中在 `constants/taxRates.js`，**改一处全局生效**，政策更新只需改常量，利于运维。
- **可扩展为云函数**：需要实名/存储用户历史时，可平滑迁移到微信云开发 `cloudfunctions`，保持算法层不变。
- **结构化返回**：所有计算函数返回对象（含明细、档位、提示文案），页面只做渲染，逻辑与视图解耦。

### 3.4 安全与合规优化

- 内置**风险提示语**和「以税务机关核定为准」免责声明，规避误导风险。
- 明确标注「房贷与房租二选一」「大病医疗仅汇算申报」等容易误用的规则。
- 政策集中管理并标注年份，避免过期政策误导用户。

## 六、变现与运营路径

1. **工具吸引流量**：免费计算器 + 政策库做搜索/分享入口。
2. **专业服务承接**：结果页展示「申报代办」「代理记账」入口，对接财税服务商按 C 端转化分成。
3. **会员增值**：年度汇算自动测算、多子女/多套房产复杂方案、历史收益曲线（付费解锁）。
4. **B 端 SaaS**：面向代账公司输出「客户批量税负测算」企业版。
5. **政策内容运营**：政策库结合时事文章（专项扣除调整、小微新政），做公众号/社群导流。

---

## 七、迭代路线

- **V0.1（当前原型）**：个人 + 小微核心测算，本地算法，税率速查，政策库。
- **V0.2**：微信云开发实名登录、云端保存用户计算档案。
- **V0.3**：汇算清缴智能退税测算、票据 OCR 录入（拍照识别专项扣除凭证）。
- **V0.4**：个体户 + 小微全税种一键测算报告，导出 PDF；接入代账服务。

## 八、使用说明

1. 用**微信开发者工具**导入本目录 `tax-miniapp/`。
2. AppID 使用「游客模式」或替换为自己的小程序 AppID。
3. 直接编译预览，核心计算为本地运行，无需配置后端。

> ⚠️ 本工具用于**税务知识普及与测算参考**，不构成专业税务意见；实际申报请以税务机关核定和最新政策为准。
