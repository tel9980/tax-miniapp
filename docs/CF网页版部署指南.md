## 三、四步部署（照着点就行）

### 第 1 步：登录 Cloudflare

浏览器打开 <https://dash.cloudflare.com>，登录你的账号（就是你绑 CF 域名的那个）。

### 第 2 步：进入 Pages

左侧菜单 → **Workers & Pages** → 右上 **Create** → 选 **Pages** 标签 → 点 **Connect to Git**。

### 第 3 步：连接 GitHub 并部署

1. 第一次会弹窗让你授权 Cloudflare 访问 GitHub，点 **授权**（Authorize）。
2. 选你的仓库 **`tel9980/tax-miniapp`**。
3. 填构建配置（**关键，照抄**）：
   - **Build command**（构建命令）：留空
   - **Build output directory**（输出目录）：填 `web`
   - 其余不用动
4. 点 **Save and Deploy**。

> 部署约 1 分钟，完成后会给你一个 `xxx.pages.dev` 的临时网址，先点开确认能打开。

### 第 4 步：绑定你的 CF 域名

1. 在刚建好的 Pages 项目里，点 **Custom domains** 标签 → **Set up a custom domain**。
2. 输入你的域名（如 `tax.你的域名.com`）→ 按提示完成。
3. Cloudflare 会自动配好 DNS，等 1~2 分钟生效。

✅ 完成！以后别人访问你的域名就能用了。

## 四、政策自动同步是怎么工作的

```
用户打开网页
   ↓
请求 /api/policy（CF Pages 边缘节点）
   ↓
CF 拉 GitHub 最新 policies.json（缓存 1 小时）
   ↓
网页拿到最新政策 → 计算器按新税率算
   ↓
万一 GitHub 拉不到 → 自动降级到内置数据，照样能算
```

- 页面顶部会显示「政策版本」和来源（已同步云端 / 本地缓存 / 内置数据）。
- 用户**什么都不用做**，政策一变，下次打开就是新的。

## 五、以后政策变了，你怎么更新

只有一步：**改数据 → 推 GitHub**。

1. 打开 GitHub 仓库 `tel9980/tax-miniapp` → `data/policies.json`。
2. 在网页上直接点编辑，改对应税率数字（比如个税起征点、税率档）。
3. 点 **Commit changes** 保存。

Cloudflare 会自动重新部署，用户下次打开自动生效。**全程免费，不用碰代码工具。**

> 不知道怎么改某个数字？把新政策文件发我，我帮你改好推上去。

## 七、常见问题

**Q：网页版和小程序有什么区别？**
小程序能在微信里搜到、转发；网页版是浏览器打开一个网址。功能完全一样，网页版还不用备案、不用审核、改起来更快。

**Q：手机能用吗？**
能。网页版是响应式设计，手机浏览器打开体验和小程序差不多，还能「添加到主屏幕」当 App 用。

**Q：用户数据会上传吗？**
不会。所有计算都在用户手机/电脑本地完成，只联网拉一次政策文件，不收集任何输入数据。

**Q：我还能做小程序吗？**
能，两套代码我都留着。小程序版等你想正式上线时，再决定是否付 19.9 元/月云开发，或者也做成网页版分享出去。
