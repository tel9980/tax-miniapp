## 二、三步免费用起来（照着点就行）

### 第 1 步：安装微信开发者工具（免费）

1. 打开官网下载页：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
2. 选你电脑对应的版本（Windows 或 Mac），下载安装
3. 装好后打开，用**微信扫码登录**

### 第 2 步：注册个人小程序（免费，拿到 AppID）

1. 打开 <https://mp.weixin.qq.com>
2. 右上角「**立即注册**」→ 选「**小程序**」
3. 用邮箱注册 → 主体类型选「**个人**」（免费，不用交认证费）
4. 注册完成后登录后台，按这个路径找到 AppID：
   - 左侧「**开发**」→「**开发管理**」→「**开发设置**」→ 页面里的「**AppID(小程序ID)**」那一串字母数字，**复制下来**

> 💡 如果只是想先试试，这一步可以跳过——导入时选「**测试号**」也能预览，但真机分享体验稍差，建议直接注册个人号（免费）。

### 第 3 步：导入项目

1. 打开微信开发者工具，点「**+**」→「**导入项目**」
2. **目录**：选择你下载解压出来的 `tax-miniapp` 文件夹
3. **AppID**：填第 2 步复制的那串 AppID（或选「测试号」先体验）
4. 点「**导入**」

### 第 4 步：真机预览（免费）

1. 点工具栏上的「**预览**」按钮
2. 会生成一个二维码
3. 手机微信**扫一扫** → 就能在手机上用了 ✅

## 三、关于"上线给更多人用"（可选，也免费）

- 个人主体小程序**可以**提交审核上线，**免费**。
- ⚠️ 一个注意点：「税务 / 金融」相关类目，个人主体可能受限制。上线时建议把小程序**描述成「个人税务知识普及与测算工具」**，归到「**工具 / 效率**」类目，避免触发金融资质要求。
- 如果审核要求企业资质，那时再考虑注册个体工商户/公司（这一步才开始涉及少量费用）。

## 五、常见问题

**Q：能直接给身边人用吗？**
A：能。真机预览的二维码可以发给微信好友，对方扫码就能用（预览版有效期有限，长期用就提交审核上线）。

**Q：计算结果准吗？**
A：算法按现行政策实现，并已本地验证。但**仅供测算参考**，实际申报请以税务机关核定和最新政策为准。

**Q：政策变了怎么办？**
A：现在的税率写死在代码里，政策变了需要更新代码重新发布。以后可以升级成"云端下发"（见 `backend-plan.md`），政策一变自动同步，不用重新发版。
