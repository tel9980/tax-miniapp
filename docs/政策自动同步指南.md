# 政策自动同步 · 小白上手指南

> 目标：以后**税收政策变了，你只改 GitHub 上一个文件，所有用户的小程序自动更新**，不用重新发版、不用重新审核。
> 全程免费，照着点就行，不懂技术也能完成。

---

## 一、先搞清楚「为什么能自动同步」

小程序的计算逻辑是「读数字」，数字从哪来决定了要不要发版：

| 方式 | 政策变了要不要重新发版 |
|---|---|
| 以前：数字写死在代码里 | ❌ 要重新发版、重新审核，很慢 |
| 现在：数字放 GitHub + 云函数自动拉 | ✅ 只改一个文件，秒级同步 |

**数据流**：你改 GitHub 上的 `data/policies.json` → 微信云函数拉取 → 用户小程序打开时自动更新。

---

## 二、前提：先完成「免费上手指南」前两步

确保你已经：
1. 装了微信开发者工具
2. 注册了小程序、拿到 AppID、能正常预览

如果还没做，先看同目录的 `免费上手指南.md`。

---

## 三、开通云开发（免费，约 3 分钟）

云开发是微信官方给小程序配的「免费小服务器」，政策同步靠它中转（因为小程序端不能直连未备案域名）。

1. 在微信开发者工具左上角，点 **「云开发」** 按钮。
2. 首次会提示开通，选 **「基础版」或「免费额度」**（个人够用，**不用花钱**）。
3. 开通后，顶部会显示一个 **环境 ID**，形如 `tax-miniapp-1g2h3j4k`，**复制它**。

---

## 四、填环境 ID（关键一步）

1. 打开项目里的 `miniprogram/app.js`。
2. 找到最上面这一行：
   ```js
   const CLOUD_ENV = '';
   ```
3. 把引号里填上你复制的环境 ID，变成：
   ```js
   const CLOUD_ENV = 'tax-miniapp-1g2h3j4k';
   ```
4. 保存。

---

## 五、部署云函数（把「拉政策」的小程序部署到云端）

1. 在开发者工具左侧目录树，找到 `cloudfunctions/getPolicy` 文件夹。
2. **右键**它 → 点 **「上传并部署：云端安装依赖」**。
3. 等提示「部署成功」。

> 如果右键没有这个菜单，先在工具栏把「编译模式」旁边切到「云开发」，或确认 `project.config.json` 里有 `cloudfunctionRoot`。

---

## 六、验证自动同步是否生效

1. 在开发者工具点 **「编译」**。
2. 打开小程序「政策库」页或任意计算页，观察：
   - 如果正常显示，说明政策数据已从 GitHub 拉取成功。
3. 想看更直接的证据：在「首页」或任意地方，版本号会变成 `2026.1` 这类（同步成功）而非 `builtin`。

---

## 七、以后政策变了，你只做一件事

比如国家把某个税率调了，你：

1. 打开 GitHub 仓库：`https://github.com/tel9980/tax-miniapp`
2. 找到 `data/policies.json`，点右上角 **铅笔图标** 在线编辑。
3. 改对应的数字（文件里有中文注释，照着改）。
4. **把文件顶部的 `"version": "2026.1"` 改成 `"2026.2"`**（版本号加一，这是触发同步的开关）。
5. 点 **「Commit changes」** 保存。

**完成。** 用户下次打开小程序，就自动用上新政策了。

---

## 八、不放心？两条兜底保命

1. **没开云开发也能用**：`CLOUD_ENV` 留空，小程序自动用内置的 `taxRates.js` 兜底数据，功能照常，只是政策更新要重新发版。
2. **拉取失败也不影响**：云函数连不上 GitHub 时，小程序自动回退到「上次缓存」或「内置数据」，绝不会因为网络问题白屏。

## 常见问题

**Q：真的免费吗？**
A：免费。个人主体小程序 + 云开发免费额度，政策同步这个用量（每天几个请求）远低于免费额度，不会扣钱。

**Q：一定要云开发吗？**
A：要「自动同步」就一定要。因为微信小程序端不能直连未备案的 GitHub/CF 域名，只能借微信官方云开发中转。这是免费方案里唯一合规的路。

**Q：我改错了政策数字怎么办？**
A：GitHub 每个文件都有历史记录，点文件 → History → 找回上一个版本即可。小程序端也是「版本号变了才覆盖」，改错会立即暴露，好排查。

**Q：CF 域名还派得上用场吗？**
A：等你以后想做「网页版」给企业主用，CF 域名正好用上（网页没有微信备案限制）。详见 `backend-plan.md`。
