# 政策自动同步 · 保姆级上手指南（小白闭眼照做版）

> 目标：以后**税收政策变了，你只改 GitHub 上一个文件，所有用户的小程序自动更新**，不用重新发版、不用重新审核。
> 全程免费。下面每一步都告诉你「点哪里、会看到什么、卡住怎么办」。

---

## 零、先明白你在做什么（10 秒看懂）

政策同步的"管道"是这样的：

```
你在 GitHub 改一个文件
        ↓
微信云函数（免费小服务器）去拉最新政策
        ↓
用户打开小程序 → 自动用上新政策
```

你只需要**装一次管道**（下面三步），以后每次政策变化，就只是"改一个文件"这么简单。

---

## 一、前提：先完成「免费上手指南」

确保你已经：
1. 装了微信开发者工具（电脑版，免费）
2. 注册了个人小程序、拿到 AppID、能打开项目、能真机预览

没做完先看同目录 `免费上手指南.md`。做完再回来。

---

## 二、开通云开发（重点，逐屏讲）

> 云开发 = 微信官方送的「免费小服务器」。政策同步靠它中转，因为小程序端不能直连未备案的 GitHub/CF 域名。

**第 1 屏：找到按钮**

打开微信开发者工具，看**顶部工具栏**，有一个**云朵图标**，旁边写着「**云开发**」两个字。点它。

> 找不到？工具栏从左到右一般依次是：编译、预览、真机调试、清缓存、上传……「云开发」通常也在这一排，是个**云朵形状**的图标。

**第 2 屏：开通**

点「云开发」后，如果还没开通，会弹出一个开通引导框：

- 会让你**填一个环境名称**（随便起，比如 `tax`，别用中文也行）
- 可能会让你**选付费方式**：选「**免费额度**」或「**按量付费（有免费额度）**」——总之**选免费的、默认的那个**，不要选"预付费套餐"，政策同步这个用量不会产生费用。
- 点「**开通**」或「**立即开通**」。

> 卡点：如果提示"需要实名认证"或"需要企业主体"，说明你的小程序是**个人主体**——个人主体也能开云开发，只是个别高级功能受限，不影响我们。按提示完成实名即可。

**第 3 屏：复制环境 ID（最关键的一步）**

开通成功后，会进入「云开发控制台」页面。**页面顶部**（或左上角）会显示一串字母数字，形如：

```
tax-miniapp-1g2h3j4k
```

这串就是「**环境 ID**」。**选中它 → 复制**（Ctrl+C / 右键复制）。

> 卡点：如果没看到环境 ID，点控制台左上角的**环境名称**，会弹出「环境列表」，里面能看到环境 ID。或者点「设置」→「环境设置」也能找到。

**把环境 ID 记下来，马上要用。**

---

## 三、填环境 ID（把管道接上）

1. 回到微信开发者工具，左侧目录树里打开 `miniprogram/app.js`。
2. 找到**最上面**这一行（大约第 6 行）：

   ```js
   const CLOUD_ENV = '';
   ```

3. 把引号里填上你刚复制的环境 ID，变成（举例）：

   ```js
   const CLOUD_ENV = 'tax-miniapp-1g2h3j4k';
   ```

4. **保存**（Ctrl+S）。

> 注意：引号要用**英文引号**（`'` 或 `"` 都行，别用中文引号 `‘’`）。环境 ID 前后不要有多余空格。

---

## 四、部署云函数（把「拉政策」的代码传到云端）

> 云函数就是那段"自动去 GitHub 拉政策"的小程序，需要上传到微信服务器才生效。

1. 在左侧目录树，找到 `cloudfunctions` 文件夹，展开后看到 `getPolicy`。
2. **右键点击 `getPolicy` 文件夹**。
3. 在弹出菜单里点 **「上传并部署：云端安装依赖」**（记住，是带"**云端安装依赖**"的那个选项）。
4. 右下角会出现进度，等它提示「**部署成功**」或「**上传成功**」。

> 卡点 1：右键没有"上传并部署"？
> 说明 `cloudfunctions` 没被识别为云函数目录。检查 `project.config.json` 里有没有这一行：`"cloudfunctionRoot": "cloudfunctions/"`（本项目已配好）。如果改了，重启开发者工具再试。

> 卡点 2：部署时报错「环境不存在」或「env 无效」？
> 说明环境 ID 填错了，或云开发没开通成功。回到第二步重新复制环境 ID，核对 `app.js` 里的 `CLOUD_ENV`。

> 卡点 3：部署失败提示"依赖安装失败"？
> 云函数只有一个 `https` 内置模块，没有第三方依赖，正常不会失败。如果失败，重试一次，或检查网络（能上网就行）。

---

## 五、验证：确认自动同步真的生效了

1. 点工具栏「**编译**」。
2. 小程序跑起来后，打开「**政策库**」页（底部 tabBar 中间的按钮）。
3. 判断是否同步成功，看首页或控制台：

   - ✅ **成功**：政策页能正常显示，且首页/控制台里政策版本号显示成 `2026.1`（而不是 `builtin`）。
   - ❌ **没成功**：版本号还是 `builtin`，说明云函数没生效，回到第四步检查部署。

> 最直观的验证：打开开发者工具的「**调试器**」→「Console」面板，看有没有报错。没有报错 + 政策页正常 = 成功。

---

## 六、以后政策变了，你只做一件事（记住这个）

比如国家把某个税率调了，你：

1. 打开 GitHub 仓库：`https://github.com/tel9980/tax-miniapp`
2. 找到 `data/policies.json`，点右上角**铅笔图标**在线编辑。
3. 改对应的数字（文件里每一项都有中文注释，照着改，别改结构只改数字）。
4. **把文件顶部的 `"version": "2026.1"` 改成 `"2026.2"`**（版本号 +1，这是触发自动同步的开关，不改版本号不会同步！）。
5. 点页面底部的 **「Commit changes」** 保存。

**完成。** 用户下次打开小程序，自动用上新政策，你不用碰代码、不用重新发版。

---

## 七、不放心？两条兜底保命

1. **没开云开发也能用**：`CLOUD_ENV` 留空，小程序自动用内置 `taxRates.js` 兜底数据，功能照常，只是政策更新要重新发版。
2. **拉取失败不白屏**：云函数连不上 GitHub 时（比如网络抖动），小程序自动回退到「上次缓存」或「内置数据」，绝不会崩、不会卡。

## 常见问题

**Q：真的免费吗？会不会哪天被扣钱？**
A：云开发是"免费额度 + 超额按量付费"。政策同步的用量（每个用户打开才拉一次，一个月几十次）远低于免费额度（百万次级），**不会扣钱**。只有以后你加了"大量用户每天高频上传数据"之类功能，才可能超额度。

**Q：一定要云开发吗？能用 CF 吗？**
A：要「自动同步到小程序」就一定要云开发（或一个已备案域名）。CF 域名未备案，小程序端连不上，和 CF 免费与否无关。CF 留着以后做「网页版」用。

**Q：我改错了政策数字怎么办？**
A：GitHub 每个文件都有历史记录：点文件 → History → 找回上一个版本。小程序端是"版本号变了才覆盖"，改错会立即暴露，好排查。

**Q：环境 ID 填错、或以后想换环境怎么办？**
A：改 `app.js` 里的 `CLOUD_ENV`，保存，重新编译即可。

**Q：政策同步了，但计算器里的数字没变？**
A：确认你改了 `data/policies.json` 的**对应数字字段** + **version 加一** + 保存提交。三者缺一不可。改完等云函数拉到（通常几分钟内，CDN 有缓存）。
