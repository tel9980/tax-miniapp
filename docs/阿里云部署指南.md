# 阿里云部署指南（小程序真机可用 · 合规路线）

> 目标：把现有的抓取 + API + 网页，从 Cloudflare 搬到阿里云一台服务器上，域名用已备案的 `1211663.xyz`。
> 好处：备案接入商（阿里云）与实际服务器一致，**完全合规**，小程序真机预览和正式发布都能过。
> 代码：`server/index.js` 已经写好，**`worker/index.js` 一行没改**，两套部署共用同一份抓取逻辑。

## 一、先确认备案还活着

服务器过期后，阿里云会取消「接入」，管局随后可能注销备案。**这一步没确认就买服务器，可能白买。**

两个查法，任选：

1. 工信部官网：https://beian.miit.gov.cn → 「ICP备案查询」→ 输入 `1211663.xyz`
2. 阿里云控制台 → 搜「备案」→ 我的备案 → 看 `1211663.xyz` 的状态

结果对应动作：

| 查到什么 | 意味着 | 要做什么 |
|---|---|---|
| 有备案号，状态正常 | 备案还在 | 买服务器 → 做「新增接入」→ 等审核 → 部署 |
| 有备案号，但接入显示「已取消」 | 备案号还在，接入断了 | 买服务器 → 新增接入（1~3 天）→ 部署 |
| 查不到 | 备案已被注销 | 重新备案（7~20 天），期间只能开发者工具用 |
| 主体信息不是你 | 别人的备案 | 得重新备案 |

## 二、买服务器

| 项 | 建议 | 说明 |
|---|---|---|
| 类型 | 轻量应用服务器 或 ECS 共享型 | 本项目 CPU 几乎不耗，1核1G 就够 |
| 配置 | 2核2G / 3M带宽 | 约 100 元/年（新用户价，以阿里云实际为准） |
| 时长 | **包年包月 ≥ 3 个月** | 备案的硬要求，按量付费的机器开不出备案服务号 |
| 系统 | Ubuntu 22.04 或 Debian 12 | Node 18+ 直接装 |
| 地域 | 随便（选离你近的） | 备案跟地域无关 |

买完在控制台记下：**公网 IP**、**备案服务号**（在服务器实例详情里生成）。

## 三、备案「新增接入」

阿里云控制台 → 备案 → 新增接入 → 填域名 `1211663.xyz` + 备案服务号。

> 网站名称别写「税收」「税务」「金融」这类词，容易被要求补充材料甚至不受理。写中性的，比如「财税资料分享」。
> 内容要与备案填写一致：本项目是**非经营性**的政策信息浏览，不放广告、不收费，符合个人备案要求。

审核期间（1~3 天）可以先部署，用 IP 或临时域名调试。

## 四、部署（服务器上执行）

项目**零 npm 依赖**，只用 Node 内置模块，不用 `npm install`。

```bash
# 1. 装 Node（Ubuntu/Debian）
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
node -v   # 需要 >= 18

# 2. 传代码（在你本地执行，二选一）
#    a) 从 GitHub 拉
git clone https://github.com/tel9980/tax-miniapp.git /opt/tax-miniapp
#    b) 直接 scp
scp -r /workspace/tax-miniapp root@<服务器IP>:/opt/tax-miniapp

# 3. 启动
cd /opt/tax-miniapp
PORT=8787 node server/index.js
# 首次访问 /api/policies 会现场抓 15 个官方源，约 20~30 秒，之后写进 data/kv.json（约 230KB）
```

## 五、常驻运行（systemd）

`/etc/systemd/system/tax-miniapp.service`：

```ini
[Unit]
Description=Tax Policy Miniapp
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/tax-miniapp
Environment=PORT=8787
Environment=DAILY_HOUR=9
ExecStart=/usr/bin/node server/index.js
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now tax-miniapp
sudo systemctl status tax-miniapp
journalctl -u tax-miniapp -f      # 看日志
```

服务内置定时任务：每天 `DAILY_HOUR` 点自动抓取一次（等价于原来 Cloudflare 的 cron）。

## 六、Nginx + HTTPS（小程序必须是 HTTPS）

```bash
sudo apt install -y nginx certbot python3-certbot-nginx
```

`/etc/nginx/sites-available/tax-miniapp`：

```nginx
server {
    listen 80;
    server_name 1211663.xyz www.1211663.xyz;

    location / {
        proxy_pass http://127.0.0.1:8787;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;   # /api/refresh 要跑 20~30 秒
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/tax-miniapp /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d 1211663.xyz -d www.1211663.xyz   # 自动签发并配置续期
```

> **别用阿里云的「免费 SSL 证书」**：现在有效期只有 3 个月，到期要手动换，容易忘。Let's Encrypt 是 90 天但 certbot 会自动续期，一次配好永久有效。

## 七、验证

```bash
curl https://1211663.xyz/api/policies | head -c 200
curl https://1211663.xyz/api/refresh          # 手动抓一次，约 20~30 秒
curl -I https://1211663.xyz/                  # 看是否 200 + https
```

浏览器打开 `https://1211663.xyz` 应该看到政策库页面。

## 八、小程序接上

1. 改 `miniprogram/config.js`：

```js
const API_BASE = 'https://1211663.xyz';
```

2. 微信公众平台 → 开发管理 → 开发设置 → **服务器域名** → request 合法域名加 `https://1211663.xyz`
3. 开发者工具重新编译 → 真机预览应该就能跑通

> 服务器域名每月只能改 5 次，一次填对。

## 九、之后怎么更新政策

自动：每天 9 点自己抓。

手动：

```bash
curl https://1211663.xyz/api/refresh
```

改代码后：

```bash
cd /opt/tax-miniapp && git pull && sudo systemctl restart tax-miniapp
```

## 十、跟 Cloudflare 版的关系

| | Cloudflare 版 | 阿里云版 |
|---|---|---|
| 入口 | `worker/index.js` + `wrangler.toml` | `server/index.js` + systemd |
| 存储 | Cloudflare KV | 本地 `data/kv.json` |
| 定时 | CF cron | 内置 setTimeout（每天定点） |
| 抓取逻辑 | 完全相同 | 完全相同（共用 `worker/*.js`） |
| 成本 | 0 元 | 约 100 元/年（服务器） |
| 备案 | 域名备不了 | ✅ 合规 |

**两套可以同时跑**，改一处抓取逻辑两边都生效（因为共用 `worker/` 目录）。

## 十一、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `/api/policies` 很慢（20~30s） | 首次没缓存，正常；之后 30ms 级 |
| 抓取后 `errors` 非空 | 总局搜索接口限流，等几分钟重试；代码有 3 次退避重试 |
| 502 Bad Gateway | Node 服务没起来，`journalctl -u tax-miniapp -n 50` 看报错 |
| 小程序报「不在合法域名列表」 | 后台服务器域名没加，或没重新编译 |
| 小程序报 HTTPS 证书错误 | certbot 没跑成功，或证书过期 |
| 数据不更新 | 看 `data/kv.json` 的 `updatedAt`；手动 `/api/refresh` 试 |
| 想清空缓存重抓 | 删掉 `data/kv.json` 重启服务，或删其中 `policies` 键 |
